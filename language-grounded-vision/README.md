A 55-minute main route: 48 physical slides, 249 reveal states and eight optional
backup slides. Right / Space / N advances; Left / P goes back. F completes or
restarts a slide. R switches between reading and presentation. Q / A / S opens
questions, answers or notes; O opens the map. D toggles the pen; Z undoes ink.

The explorer compares five spatial interfaces using authored reference examples
and seven recorded Grounding DINO tiny + SAM base runs. All 15 detections and
masks are retained, including failures. Generative and reasoning modes contain
reference examples only. The browser replays saved results and needs no model
download. Both HTML pages embed their images, styling, scripts and data.

This lecture follows [From CLIP to Vision-Language Models](../from-clip-to-vlm/)
in the [attention, vision and language series](../).
