# Vision I lecture assets and verification

Generated by `src/build_vision1_lesson.py` from the numerical worksheet, original diagrams and saved experiment results. The complete output is `vision1.html`; 58 teaching frames plus cover. `frame-manifest.json` lists the exact section, frame number, caption and presenter notes.

## Provenance

- `newfoundland_31.jpg` and `Persian_98.jpg`: Oxford-IIIT Pet dataset, via `timm/oxford-iiit-pet`, revision `089695c834a7deb60505b7cc506672db1c31a6aa`, test rows 0 and 9. See `images.json` for source links, original dimensions, SHA-256 and attribution. CC BY-SA 4.0 attribution is retained; original copyright remains with the image owners.
- `model-input.png`: the exact 224×224 checkpoint evaluation crop, normalization reversed for display.
- `real-inference.json`: saved probabilities for the exact photos, checkpoint identity, preprocessing and library versions; regenerated by `notebooks/vision/run_real_images.py`.
- `inspection.json`: raw probabilities for specified attention rows and four predetermined quadrant occlusions; regenerated by `notebooks/vision/inspect_real_vit.py`. CLS-source mass is stored separately from the 14×14 patch grid. Head-comparison plots use a common linear scale.
- `training.json`: actual full small-ViT training history, validation checkpoint selection and final test results, with seeds and hyperparameters. Regenerated by `notebooks/vision/train_small_vit.py`; the two small checkpoints live beside that script.
- Original SVG diagrams and the exact four-patch worksheet are generated by this teaching series. Diagrams are embedded in the standalone deck.

## Verified

`checks.json` records NumPy/PyTorch/JavaScript parity to 1e-12, all four worksheet cases, normalized attention rows, image checksums, links, captions and the executed notebook. The full notebook also checks Conv2d/Linear equivalence, the exact class-bias gradient, LayerNorm/GELU examples, complete-model gradients and saved-checkpoint test results.

Browser review covered all final slide layouts at 1280×720, numerical/code/map visual samples, phone reading at 390×844, and both live controls. All content is silent. See `browser-review.json` for the checked dimensions and interactions.

## Scope

The hand-set worksheet is an arithmetic example, not a natural-image recognizer. The small-model test is one-seed in-distribution synthetic generalization. Two real-photo predictions are inference demonstrations, not a Pets accuracy benchmark or a claim that these images never appeared in pretraining. Attention and occlusion illustrate measurements and their limits; they are not presented as causal explanations.
