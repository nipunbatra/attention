About the data and thresholds

These are constructed teaching predictions, not output from a running model. The generated photograph and saved candidates are bundled in this file; there is no model download or network dependency.

Score filtering retains scores at least the cutoff. NMS suppresses a competing candidate only when its IoU is strictly greater than the NMS threshold. Class-aware NMS compares matching class labels only. The ambiguity example changes B's label without changing its score, box or colour.
