Connect the token IDs to the loss, then to generation and the fixed-context limit.

Three summaries

We have built a complete character language model. Three token IDs select embedding rows. Concatenation keeps their positions separate, the MLP produces one logit per vocabulary token, and softmax gives us probabilities. Cross-entropy scores the observed next character; its gradients train every learned table and matrix. To generate, we run the same model, sample a character, append it, shift the window, and repeat. This works, but $W_1$ fixes the window width. Part 2 keeps the next-token objective and changes how a token gathers information from its preceding context.

Intuitive

Use the last few characters to guess what character tends to come next.

Operational

Look up embeddings, concatenate the window, run the MLP, apply softmax, then sample or score the observed target.

$$\pIn{a_0}=[\pIn{e_1},\ldots,\pIn{e_w}]$$

Place the $w$ embedding rows side by side to form the input row.

$$\pAct{a_1}=\tanh(\pIn{a_0}\pParam{W_1}+\pParam{b_1})$$

Hidden activations combine the input row using learned weights and bias.

$$\pProb{p}=\operatorname{softmax}(\pAct{a_1}\pParam{W_2}+\pParam{b_2})$$

Next-token probabilities come from transforming the hidden row with the output weights and bias, then applying softmax.

e = embedding(ctx)
a0 = e.flatten(1)
a1 = torch.tanh(hidden(a0))
z = output(a1)
p = z.softmax(dim=-1)

Lookup and concatenate. Calculate the hidden activations. Produce vocabulary scores. Normalize them into probabilities.

During training, send z and an observed target to cross-entropy. During generation, sample from p and form the next context.
