Why we are here: the loss can improve future predictions only by changing the model's learned numbers.

Learn the embeddings and the weights

The optimizer changes every parameter that helps produce the loss: the embedding table, both weight matrices, and both bias rows. For one context, only the embedding rows that were looked up receive a direct embedding gradient, while the shared MLP parameters receive gradients through the whole calculation. Repeating this over many shuffled training rows lowers the average loss. The curve records the training loss at regular checkpoints. The before and after bars use the same aab context with two saved parameter sets, so the change comes from training rather than from a different input.
