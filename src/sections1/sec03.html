Why we are here: an MLP needs a fixed input width, so we must choose how many earlier characters it receives.

Choose a context length

A one-character window is small but forgets almost everything. A window containing the whole prefix would change length from one training row to the next, which a plain MLP cannot accept without another design choice. We begin with three previous characters. Padding with the boundary makes even the first prediction fit that width. Sliding the window across aabid yields six context-target pairs: five letters and then the ending boundary. The split between training and held-out names happens before these windows are made, so examples from one name never cross the split.
