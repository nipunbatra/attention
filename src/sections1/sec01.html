Language tasks ask for different outputs, but all use text to make predictions.

What can a network do with text?

A network can label a passage, label each token, translate between languages, shorten a notice, answer a question from context, or continue a prompt. These tasks need different output shapes. Generation leaves more room for choice: several continuations may fit the same prefix. We give the network a precise job anyway. It must assign a probability to every possible next token. Choosing or sampling one token then gives us a continuation. This gives us a small prediction task to build with embeddings, an MLP, softmax, and cross-entropy.
