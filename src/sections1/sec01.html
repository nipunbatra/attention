Language tasks ask for different outputs, but all use text to make predictions.

What can a network do with text?

Before choosing a network, decide what its output should mean. A spam detector assigns one label to an email. An entity tagger attaches labels to words. Translation, summarization, and question answering return text. The examples below illustrate these tasks; they are not outputs of the character model we build later.

Choose a word, append it to the text, then predict again.

We’ll learn from a list of Indian given names, with one name per row.

aabid, aabida, aachal, …

Then we’ll generate a name: choose the next letter, append it, and repeat until the name ends.

We can produce a sequence by repeatedly predicting one next token. A token is a unit of text. We will start with characters, so every prediction chooses a letter or an ending marker. This keeps the vocabulary small enough to inspect each probability.
