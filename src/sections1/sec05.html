Why we are here: three embedding rows must become one fixed-width input without losing their positions.

Concatenate the embeddings

The lookup returns one embedding row for each character in the window. The MLP expects one row, so we place the three embeddings side by side. This makes a six-number vector because the window has three positions and each embedding has two coordinates. Each segment keeps its position: the first two numbers always describe the oldest character, and the last two describe the newest. Reversing the characters therefore changes the concatenation. Adding the same rows would erase their order because addition is commutative. The trained values below come directly from the embedding table you just inspected.
