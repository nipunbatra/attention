Why we are here: training and generation run the same forward pass but obtain the next token in different ways.

Training and generation

During training, the data provides both the context and the observed next character. The model produces probabilities, cross-entropy scores the observed target, and the optimizer changes the parameters. Many windows can be processed in a batch because every window has the same shape. During generation, the next character is unknown. The model produces the same kind of distribution, then a rule chooses one character. That choice is appended to the context and becomes part of the next input. There is no target and no parameter update. The difference lies around the shared forward pass, not inside it.

Keep in mind: training changes the model from observed targets, while generation holds the model fixed and extends the sequence.
