Why we are here: attention moves information between token rows, then a feed-forward network transforms features within each row.

Attention mixes rows; the FFN mixes features

A Transformer block alternates two kinds of mixing. Attention holds one receiving token fixed and combines value rows from several source positions. The feed-forward network holds one position fixed and combines the features inside that row. The same feed-forward weights are applied independently to every token. In this illustration, a five-number representation is projected to eight hidden numbers, ReLU sets negative hidden values to zero, and a second projection returns to five numbers so the result can join the residual stream. The weights are hand-picked one-decimal values used only to make the arithmetic visible.

Across token rows

Attention combines $\vv{v_j}$ from positions $j\le i$ using $\va{\alpha_{ij}}$.

Within one row

The FFN transforms the coordinates of one token with shared weights.
