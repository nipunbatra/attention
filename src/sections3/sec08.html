Attention gathers information from other token rows. The feed-forward network then works on the features inside each row.

Attention mixes rows; the FFN mixes features

For one receiving token, attention combines value rows from several source positions. The feed-forward network (FFN) works within that token's row, combining its features. We apply the same FFN weights independently to every position. In the example below, a five-number representation becomes eight hidden numbers. ReLU replaces negative hidden values with zero, and a second projection returns to five numbers so we can add the result to the residual stream. We chose one-decimal weights to keep the arithmetic readable.

Across token rows

Attention combines $\vv{v_j}$ from positions $j\le i$ using $\va{\alpha_{ij}}$.

Within one row

The FFN transforms the coordinates of one token with shared weights.
