Why we are here: one causal forward pass can make a next-token guess at every position without reading any target early.

Train every position at once

Each input token supplies a training target when water is appended as the observed continuation. The first position predicts fisherman, the next predicts sat, and the final position predicts water. The causal mask keeps each row honest: row $i$ can read only positions at or before $i$. The model still computes all rows in parallel because the mask removes forbidden score cells before softmax. We average the position losses, run one backward pass, and update the shared parameters once. Some positions improve more than others after this single step, so the mean is the quantity the optimizer follows.
