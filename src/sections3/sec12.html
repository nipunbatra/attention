Why we are here: the complete model still learns from the same next-token cross-entropy used by the small character model.

Training: one pass, many guesses

The complete decoder processes a token sequence once and produces a vocabulary distribution at every position. Shifting the observed sequence by one position supplies the targets. The causal mask ensures that each prediction uses only its prefix, so all position losses are valid next-token losses. Averaging them gives one scalar objective for the backward pass. This is the same statistical task used by the Part 1 aabid character model. The architectures differ in how they build a context representation: the character MLP concatenates a fixed window, while the Transformer uses causal attention and stacked blocks over the available prefix.

Parallel next-token objective

$$L=\frac{1}{T}\sum_{i=1}^{T}-\log p(x_{i+1}\mid x_{\le i})$$

aabid character MLP

Fixed window $\to$ concatenated embeddings $\to$ hidden layer $\to$ logits.

$$L=-\log p(\text{next character})$$

Decoder-only Transformer

Available prefix $\to$ causal blocks $\to$ final row $\to$ logits.

$$L=-\log p(\text{next token})$$

The next-token objective is unchanged; the Transformer builds its context representation with causal attention and depth.
