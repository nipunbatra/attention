Training: one pass, many guesses

One pass through the decoder produces a vocabulary distribution at every position. Shift the observed sequence by one position to get the targets. Because the causal mask limits each row to its prefix, we can use every row for next-token training. We average those losses into one scalar for the backward pass. The Part 1 aabid character model learned the same statistical task. What differs is how the models build their context representation: the MLP concatenates a fixed window, while the Transformer uses causal attention and stacked blocks over the available prefix.

Parallel next-token objective

$$L=\frac{1}{T}\sum_{i=1}^{T}-\log p(x_{i+1}\mid x_{\le i})$$

aabid character MLP

Fixed window $\to$ concatenated embeddings $\to$ hidden layer $\to$ logits.

$$L=-\log p(\text{next character})$$

Decoder-only Transformer

Available prefix $\to$ causal blocks $\to$ final row $\to$ logits.

$$L=-\log p(\text{next token})$$

The next-token objective is unchanged; the Transformer builds its context representation with causal attention and depth.
