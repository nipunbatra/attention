Why we are here: comparing the Transformer with the Part 1 character MLP isolates the change in how context is represented.

Back to aabid

The aabid character model and the Transformer both embed discrete symbols, produce logits, apply softmax, and learn from next-token cross-entropy. Their main difference lies between the embeddings and the output head. The character MLP concatenates a fixed number of previous embedding rows, so its context size is chosen in advance and each window slot has separate input weights. The Transformer keeps one row per token, uses causal self-attention to gather from any allowed prefix position, and repeats attention and FFN updates through a stack. This comparison turns the larger architecture into a change of context builder rather than a new learning objective.
