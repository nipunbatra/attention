Compare the Transformer with our character MLP. How has the way we represent context changed?

Back to aabid

Both models embed discrete symbols, produce logits, apply softmax, and learn from next-token cross-entropy. The main difference is between the embeddings and the output head. Our aabid MLP concatenates a fixed number of previous embedding rows. We choose its context size in advance, and each window slot has separate input weights. The Transformer keeps one row per token and uses causal self-attention to read from any allowed position in the prefix. It then repeats attention and FFN updates through a stack. We have changed how the model builds context, while keeping the next-token learning objective.
