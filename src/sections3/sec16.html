An attention map shows how values are mixed. It cannot tell us everything about the model's answer.

What attention gives, and what it does not

Each receiving token uses attention to combine value rows from allowed positions. Learned projections compute the weights from the current representations, so the pattern can adapt to the input and shorten paths between distant tokens. An attention map alone does not guarantee correct facts, sound reasoning, a complete explanation, or unlimited memory. One head may handle several relations, and several heads may share a relation. The causal mask is needed during training as well as generation. Context length is finite, and computing the scores has a cost. Use the checks below to distinguish what the calculation shows from what would need more evidence.

What it gives

Learned routing that depends on the current representations and respects the mask.

A direct within-layer path between allowed token positions.

What it does not ensure

Correct facts, reliable reasoning, complete explanations, or memory beyond the available context.

Test the claims

Attention weights tell us how the model mixed value information. We need other evidence to explain its broader behavior.
