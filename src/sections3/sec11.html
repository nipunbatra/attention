The complete decoder-only model

Our pre-norm decoder-only Transformer starts with token embeddings plus positions. Causal blocks update those rows, and a final LayerNorm prepares them for a linear vocabulary readout. Each block preserves model width. Training uses the distributions at all valid positions; generation chooses the next token from the last position’s distribution. This arrangement follows the GPT-2 implementation, which ties its linear readout to the token embedding table and has no separate output bias. The schematic permits an optional bias. Its nonlinear FFNs sit inside the blocks. This is a different architecture from our numerical one-head toy, whose final predictor remains a 4 → 8 → 20 ReLU MLP. The worksheet below runs that toy, not the full stack.
