The complete decoder-only model

Our pre-norm decoder-only Transformer starts with token embeddings plus positions. Those rows pass through a stack of causal blocks, then a final LayerNorm before the vocabulary head. Every block preserves model width, so we can keep adding residual updates. The vocabulary head maps each normalized final row to one logit per vocabulary token, and softmax turns those logits into probabilities. Training can use a loss at every position; generation uses only the last position's distribution to choose the next token. The GPT-2 implementation also uses this final normalization.
