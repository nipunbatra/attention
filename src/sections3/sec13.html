Why we are here: training scores every position together, while generation appends one chosen token and repeats the forward pass.

Generation: one token, then again

Generation starts with a prefix and reads the probability distribution at its last position. A decoding rule chooses one token, appends it, and runs the model for the new last position. The process repeats until a stopping rule fires. Recomputing every earlier key and value would waste work because causal attention cannot change them when a later token is appended. A KV cache stores those earlier projections and adds one new key and value per layer at each step. The cache saves projection work, though the new query still scores all cached keys.
