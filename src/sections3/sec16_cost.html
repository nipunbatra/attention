Scope of the comparison

These counts use conventional dense matrix multiplication, one sequence and one attention head. Bias additions, nonlinearities, lookup/data movement and optimizer state have separate costs. Training on all positions, scoring all positions, and generating from one final row are different workloads. Concatenation fixes a window width; a running mean discards slot assignments; attention retains source rows and uses a query-dependent mixture. None of these arithmetic counts proves that one method is faster on a particular device or more accurate on a task.
