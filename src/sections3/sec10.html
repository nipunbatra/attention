One block, then many

One pre-norm decoder block adds two updates to the residual stream. LayerNorm first prepares the current rows for causal multi-head attention. Attention gathers information across positions, and we add its result back. A second LayerNorm prepares the resulting rows for the FFN, which mixes features at each position and returns the second update. Later blocks can use representations that earlier blocks have already changed. Within one block, however, every query, key, and value comes from that block's input rows. Other tokens cannot read a newly updated bank row until the next block. The multi-hop example below shows what this extra depth allows.

$$\ve{u}=\ve{e}+\operatorname{MHA}(\operatorname{LN}(\ve{e}))$$ $$\vp{e'}=\ve{u}+\operatorname{FFN}(\operatorname{LN}(\ve{u}))$$
