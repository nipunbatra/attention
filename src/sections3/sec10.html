Why we are here: a Transformer block combines pre-norm attention and a pre-norm FFN, then the model repeats that block.

One block, then many

One pre-norm decoder block has two residual updates. First, LayerNorm prepares the current rows, causal multi-head attention gathers information across positions, and the result is added back. Second, another LayerNorm prepares those intermediate rows, the FFN mixes features at each position, and its result is added. Stacking blocks lets later attention use representations already changed by earlier context. Inside any one block, every query, key, and value comes from that block's input rows, so a newly updated bank row becomes available to other tokens only in the next block. The multi-hop example shows why depth can matter.
