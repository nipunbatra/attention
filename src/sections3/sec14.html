Why we are here: the same attention calculation supports encoders, decoders, and models that connect the two.

Three ways to arrange blocks

Transformer families differ mainly in which blocks they keep and which attention masks they use. Encoder-only models let every token read the full input, which suits tasks that consume a complete sequence. Decoder-only models use causal self-attention and generate one token after another. Encoder-decoder models first build source representations, then let decoder queries read encoder keys and values through cross-attention. The cross-attention arithmetic is unchanged: compare a query with keys, apply softmax, and mix values. What changes is where the three projected rows come from. The 2017 Transformer paired an encoder stack with a decoder stack.
