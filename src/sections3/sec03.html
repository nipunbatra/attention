Why we are here: the graph contains stored parameters and temporary results, and only the stored parameters survive the example.

Which numbers will the optimizer change?

The forward pass creates many rows and matrices, but they do not all have the same status. Token and position tables, projection matrices, and the vocabulary head are parameters. Training changes them and saves the new values. The rows $\ve{e}$, $\vq{q}$, $\vk{k}$, $\vv{v}$, the scores, weights, messages, updates, logits, and probabilities are intermediates. They are recomputed when a new sequence arrives. Autograd retains enough of these temporary values to calculate gradients, then the optimizer updates the parameters. This distinction prevents a common mix-up: $\vd{\Delta e}$ changes a representation inside a forward pass, while an optimizer step changes stored weights.
