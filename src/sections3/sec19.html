Summarize one training step, one block, and the generation loop.

Three summaries

We trained the Part 2 toy by comparing its prediction with an observed token, computing gradients, and taking an SGD step. We then built a larger architecture: pre-norm attention and an FFN each add a residual update inside a block. A stack of those blocks, followed by final LayerNorm and a vocabulary readout, produces next-token distributions. Generation appends a chosen token and repeats with fixed parameters, reusing cached keys and values.

Learning

Score the observed target, compute gradients, and update stored parameters.

One block

Attention mixes positions; the FFN mixes features. Each normalized branch adds a residual update.

The model

Causal blocks → final LayerNorm → vocabulary scores. Choose a token and repeat with fixed parameters.
