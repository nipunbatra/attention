Summarize one training step, one block, and the generation loop.

Three summaries

For one training example, the observed next token gives us a loss. Reverse-mode autodiff computes gradients, and SGD updates the contributing parameters. Inside one block, LayerNorm prepares the residual rows, multi-head attention gathers information across allowed positions, and the FFN mixes features within each position. The language model passes token and position rows through a stack of these causal blocks and uses the vocabulary head to get next-token probabilities. During generation, we append one token at a time and reuse cached keys and values. The cards below separate these three views of the same model.

Learning

Observed target $\to$ cross-entropy $\to$ gradients $\to$ one parameter update.

One block

Pre-norm causal multi-head attention and a pre-norm FFN each add an update to the residual stream.

The model

Embeddings plus positions $\to$ stacked causal blocks $\to$ vocabulary logits $\to$ repeated generation.
