Why we are here: the loss depends on every earlier operation, so the backward pass follows the same connections in reverse.

The forward pass is a graph

A computational graph records which result came from which inputs. The river example begins with token and position lookups, then forms projections, attention scores, softmax weights, a value mixture, the output projection, a residual sum, vocabulary logits, and the loss. Reverse-mode autodiff starts from the loss and sends a derivative through each retained edge. When one value feeds two branches, its gradient receives contributions from both. That detail matters for the residual path: the final representation reaches the loss directly through the addition and indirectly through attention. The stored training block contains the resulting gradient for every parameter used by this example.
