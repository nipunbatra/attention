The computation branches at E and joins again at the value mixture and residual sum.

The forward pass is a graph

The learned token table $E_{\text{tok}}$ and position table $P$ give us the current row stack $\ve{E}$. We project that same stack three ways: $Q=EW_Q$, $K=EW_K$, and $V=EW_V$. Query-key scores determine the attention weights $A$. The value branch supplies the vectors that $A$ mixes. The message matrix $H=AV$ becomes $\Delta E=HW_O$, then the residual sum gives $E'=E+\Delta E$. The vocabulary head maps the final row to logits, which we compare with the observed target to calculate the loss. This is still the simplified one-head model from Part 2. We will add the full pre-norm Transformer later.

Autograd follows these dependencies backward using the chain rule. Where paths meet, their gradient contributions add. The input $E$ receives a contribution through the direct residual path and others through attention. Both routes start from the input $E$, not the final $E'$. Gradients also reach every projection and the lookup rows used by this example. We do not optimize the target token or the fixed causal mask; they are data.

The same $E$ feeds all three projections and the residual path.

Each stored parameter $\theta$ receives a same-shaped gradient $\partial L/\partial\theta$.
