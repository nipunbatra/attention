To learn from a prediction, we need to know which token actually came next.

The observed next token tells us the error

The river prefix ends with the word the. The model assigns a probability to every vocabulary token before we reveal the observed continuation: water. Cross-entropy takes the negative logarithm of the probability assigned to water. If that probability is high, the loss is small; if it is low, the loss is large. The other logits still matter because they share the softmax denominator. You can inspect that denominator in the worksheet, then follow the water row into the loss calculation. Both use the same forward pass as Part 2.
