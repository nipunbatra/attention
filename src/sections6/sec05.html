Match another view without using its class label.

DINO: a teacher supplies the target

DINO uses a student network and a teacher with the same architecture but different parameters. Each consists of a backbone and an output head. The student predicts a probability distribution from one view; the target is the teacher's distribution from another view. The teacher branch is detached from the loss. Instead of receiving gradients, its parameters track an exponential moving average of the student's parameters.

The student learns through cross-entropy. The teacher changes through an exponential moving average, or EMA.

For this calculation, use three output slots. They are not labels such as cat, dog, or tree.

$p_t=\operatorname{softmax}((z_t-c)/\tau_t)$, with $c=(0.5,0.5,0)$ and $\tau_t=0.5$.

Teacher target fixed. Student logits are $(a,1,0)$ with $\tau_s=1$.

target = ((teacher_logits - center) / tau_t).softmax(-1).detach()
log_student = (student_logits / tau_s).log_softmax(-1)
loss = -(target * log_student).sum(-1).mean()

One parameter: $\phi_{\mathrm{new}}=0.9(1)+0.1(3)=1.2$. This averages parameters, not image pixels.

  • Centering: subtract a running mean of teacher outputs so one output slot does not dominate persistently.
  • Sharpening: a lower teacher temperature makes each target more selective.
  • EMA teacher: targets change more slowly than the gradient-updated student.

These work together in DINO's training recipe. Centering alone is not a guarantee against collapse.

The calculator uses teacher logits $(2,1,0)$ and centre $(0.5,0.5,0)$, giving temperature-scaled logits $(3,1,0)$. Every probability and loss term is calculated from those numbers. Its cross-entropy is $-\sum_c p_{t,c}\log p_{s,c}$. When student and teacher distributions match, this soft-target loss equals the teacher distribution's entropy, rather than zero.

The actual DINO recipe pairs different crops of the same image, with the teacher restricted to global views and the student receiving local views too. The centre is a running average of teacher outputs over training batches. Teacher EMA supplies a slowly changing target network; it does not create external supervision or semantic class labels.

After training, representations from the backbone can be evaluated without retaining this particular output head. See Emerging Properties in Self-Supervised Vision Transformers. This section describes the original DINO mechanism, not every later DINO-family training recipe.
