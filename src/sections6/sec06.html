I-JEPA predicts a target representation

I-JEPA, the Image-based Joint-Embedding Predictive Architecture, predicts representations of hidden target regions from a visible context. Its target is not the raw pixel row. A target encoder first processes the complete image; the training program then selects the encoded rows at the target positions. A separate context encoder sees the visible context, and a predictor uses those context representations plus the requested target positions.

The target encoder chooses the feature space through its learned parameters. We do not assign a coordinate called “object meaning”.

The context branch cannot read patch 4. The target branch can, because it supplies the training target.

with torch.no_grad():
    target = target_encoder(full_rows)[target_ids]
pred = predictor(context_encoder(visible_rows), target_pos)
loss = (pred - target).square().mean()

Gradients update the context encoder and predictor. EMA updates the target encoder.

The target-position vectors tell the predictor where to predict. They do not reveal the missing pixels.

At inference, the pretrained encoder represents the supplied image. It need not run a hidden-region prediction exercise for every downstream task.

I-JEPA's target rows are contextual: the target encoder has processed the whole image before the rows are selected. Its parameters are an exponential moving average of the context encoder's parameters. The predictor is trained with the context encoder, while the target is treated as fixed for each backward pass. The two encoders therefore do not share one gradient-updated parameter object.

The published method samples several target blocks and a larger context block, excludes target regions from the context, and predicts the selected features. Our single hidden patch is an architecture illustration, not a reproduction of its masking recipe or trained predictions. The code shows a mean-squared feature loss to make the target space explicit; it does not reproduce every implementation detail of the paper.

Predicting features can reduce the requirement to reproduce every pixel detail, but it does not guarantee that learned features are semantic or useful for every task. See Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture.
