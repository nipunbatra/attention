The encoder sees less than the decoder.

MAE: hide patches, reconstruct pixels

A masked autoencoder, or MAE, has an asymmetric design. Its main encoder processes only the visible patch rows. A smaller decoder then receives those encoded rows and learned mask tokens in the missing positions. The decoder predicts pixel values. Hiding patches removes input rows from the expensive encoder; it does not merely cover their pixel values while leaving all rows in place.

patch_rows = patch_pixels @ W_patch + patch_bias + pos
encoded = encoder(patch_rows[visible])

Four patches, three hidden: one visible patch row. This schematic omits the CLS token.

decoder_rows = restore(encoded @ W_dec, mask_token, visible)
pred_pixels = decoder(decoder_rows + decoder_pos)

The pixel decoder helped create a training signal. It is not needed for a recognition task.

Use the full image, then evaluate or fine-tune the pretrained encoder with a suitable task head.

The original MAE experiments often hide 75% of the patches. Our three-of-four example has that ratio, but it is not a required constant. Mask ratio, patch size, decoder design, and data all affect the training problem.

The decoder predicts the pixel row for each patch. Reconstruction loss is computed only on masked patches. The paper also studies per-patch normalised pixel targets; our numerical exercise uses the original grayscale numbers, without that normalisation. The two-line decoder code names a schematic restore operation rather than a built-in PyTorch function. See Masked Autoencoders Are Scalable Vision Learners.
