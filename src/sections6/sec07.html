What did the encoder learn?

Pretraining produces encoder parameters, not a guarantee of task performance. A linear probe freezes the encoder and trains a linear classifier on labelled examples. Fine-tuning updates some or all of the pretrained encoder along with the task head. These measure different things, so comparisons should state the data, task, training protocol, and whether the backbone was frozen.
