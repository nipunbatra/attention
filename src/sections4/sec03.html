Suppose the French prefix is <bos> la. To predict its next token, the decoder uses the row at la, the last known target position. We start from the target embedding table and target position vectors. Masked self-attention then lets la read itself and the start marker. The English source enters in the next block, cross-attention. We label the target input row $e_i^{\mathrm{tgt}}$ and the row after this first decoder block $e_i^{\mathrm{self}}$.
