Same input–target pairs, same vocabulary. Attention will replace the way context reaches the prediction head.

optimizer.zero_grad()

loss.backward()                    # compute gradients
optimizer.step()                   # change learned parameters

If the target is “red”, training raises its probability when the current prediction is wrong. PAD is never a target.

One target per window → one final query. $d_k$: query/key width. $d_v$: value width. $B,w,d,h,C$ are unchanged.

E = token_embedding(X) + position_embedding(positions)
q = W_Q(E[:, -1:, :])   # [B, 1, d_k]: final known token
K = W_K(E)             # [B, w, d_k]: source matches
V = W_V(E)             # [B, w, d_v]: source information
scores = q @ K.transpose(-2, -1) / sqrt(d_k)
scores = scores.masked_fill(X[:, None, :] == PAD, -inf)
A = scores.softmax(-1)                 # [B, 1, w]

PAD gets weight 0. Real-source weights sum to 1. The final query has no future tokens to read; all-query views also need a causal triangle.

message = A @ V                       # [B, 1, d_v]
update = W_O(message).squeeze(1)       # [B, d]
final = E[:, -1, :] + update           # [B, d]
logits = vocab_head(relu(hidden_layer(final)))

The message is not the prediction. The head converts the updated final vector into $C$ next-token scores.
