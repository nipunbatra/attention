4. The attention forward pass · Step 40 / 67 Notebook step ↗

The position table has four rows, one for each context slot. Token and position vectors both have width four, so addition preserves the width.

token_rows = attention.token_embedding(X)
position_rows = attention.position_embedding(torch.arange(w))

4. The attention forward pass · Step 41 / 67 Notebook step ↗

For example 1 the final known token is a. Its four-number input row maps to three query coordinates.

q = attention.W_Q(E[:, -1:, :])

4. The attention forward pass · Step 42 / 67 Notebook step ↗

All four source rows map to keys of width three. Query and key widths match because we will take their dot products.

K = attention.W_K(E)

4. The attention forward pass · Step 43 / 67 Notebook step ↗

W_V maps each source to a two-number value. These coordinates carry information into the weighted message.

V = attention.W_V(E)

4. The attention forward pass · Step 44 / 67 Notebook step ↗

Each score is a three-term dot product divided by √3. The result has one row of four source scores per example.

raw_scores = q @ K.transpose(-2, -1)
scores = raw_scores / math.sqrt(d_k)

4. The attention forward pass · Step 45 / 67 Notebook step ↗

Example 0 has PAD in its first slot, so that score becomes −∞. All slots of example 1 are real tokens.

pad_mask = X[:, None, :].eq(vocab.pad_id)
masked_scores = scores.masked_fill(pad_mask, float('-inf'))

4. The attention forward pass · Step 46 / 67 Notebook step ↗

Subtract the largest score, exponentiate and divide by the row sum. This softmax runs over context slots.

source_exp = (masked_scores - masked_scores.amax(-1, keepdim=True)).exp()
A = source_exp / source_exp.sum(-1, keepdim=True)

4. The attention forward pass · Step 47 / 67 Notebook step ↗

For example 1, multiply each two-number value by its source weight and add the four contributions. The result is one two-number message.

message = A @ V

4. The attention forward pass · Step 48 / 67 Notebook step ↗

The message has width two, but the original input has width four. The learned W_O is 2×4 in row-vector notation.

update = attention.W_O(message).squeeze(1)

4. The attention forward pass · Step 49 / 67 Notebook step ↗

The residual addition now combines two vectors with the same width. The updated row enters an eight-unit ReLU layer and then the ten-class vocabulary head, just as in the MLP path.

final = E[:, -1, :] + update
hidden_att = torch.relu(attention.hidden_layer(final))
logits_att = attention.vocab_head(hidden_att)
