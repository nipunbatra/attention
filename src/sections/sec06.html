Why we are here: hard retrieval chooses the single best match. Attention returns a mixture. We go back to the gradient question (query 1) with the same keys and values as before.

Hard retrieval → soft retrieval

Our hard-retrieval baseline picks the best-scoring item and returns its value. Attention instead blends values according to how well each key matched the query. This section makes that blend a spreadsheet: the scores from the previous section feed a softmax, the weights fill the $\va{\alpha_j}$ column, every value row is scaled by its weight, and the footer adds the rows up. Start in hard mode, where one row carries all the weight, then switch to soft and lower the temperature to watch the two modes meet. Drag a score up and watch every weight move. The sentence to remember: attention returns a weighted mixture of values, not one value.

In our hard-retrieval baseline, choose the key with the largest score and return that item's value:

$$j^* = \arg\max_j\, \vq{q}\cdot \vk{k_j}, \qquad \text{return } \vv{v_{j^*}}$$
If two items are useful, why return information from only one?

The scores from the gradient-information query

First exponentiate each score: $s_j\mapsto e^{s_j}$.

Then divide each result by the same total:

$$\va{\alpha_j}=\frac{e^{s_j}}{\sum_r e^{s_r}}$$
These weights are shares over input items, not probabilities of the next word.

Attention returns a weighted mixture of information for the current query—not another set of match scores.

A score changed by a slider no longer equals the original dot product. Treat it as a controlled intervention on the matching result, as if the key had changed.

In soft mode the weights are $\va{\alpha_j} = \operatorname{softmax}_j(s_j/\tau)$. A small $\tau$ makes the mixture sharper. As $\tau \to 0$, soft retrieval becomes hard retrieval when one score is strictly the largest; tied top scores keep sharing the weight. $\tau = 1$ is the formula above.

$\va{\alpha}=\operatorname{softmax}(s/\tau)$: smaller $\tau$ → sharper weights.

Each piece now has a job. A Query says what the searcher needs, Keys decide who matches, Values carry what comes back, and softmax turns scores into a mixture. Back to language.

Keep in mind: the scores decide the weights, the weights decide the mixture, and a change in one score moves every weight at once, because the softmax keeps them summing to 1.
