Why we are here: the retrieved message $m_i$ must get back into the token’s representation. This is the centre of the whole story.

The contextual update Δe

This is the step the whole page builds towards. The message $m_7$ is a mixture of values, so it lives in value space with three coordinates. $W_O$ maps it into the four coordinates of a representation, and that vector, $\vd{\Delta e_7}$, is added to $\ve{e_7}$. The original representation is not overwritten; it receives a correction that depends on context.

Press Play, or step through, and watch the highlight move down the diagram while the matching row of the table lights up. Hover a cell of the last row to see the addition. Read the axis names: the message speaks in value coordinates, $W_O$ turns them into representation coordinates. The sentence to remember: attention adds a context-dependent update to the representation it started from.

The message $m_i$ lives in value space ($d_v$ numbers). An output projection $W_O$ maps it into representation space ($d_{\text{model}}$ numbers). We call that vector the contextual update $\vd{\Delta e_i}$ and add it to $\ve{e_i}$.

$$m_i = \sum_{j \le i} \va{\alpha_{ij}}\, \vv{v_j} \qquad \boxed{\vd{\Delta e_i} = m_i\,W_O} \qquad \boxed{\vp{e_i^{\text{new}}} = \ve{e_i} + \vd{\Delta e_i}}$$

Where we are in the pipeline

Look at: the dashed edge carries $\ve{e}$ around attention unchanged; the update joins it at the plus.

The update chain, one coordinate per column

The output projection: $m_7$ (value space, $1 \times d_v$) $\to$ $\vd{\Delta e_7}$ (representation space, $1 \times d_{\text{model}}$)

Attention does not replace the existing representation. It computes context-dependent information that can be added to it.
Calling this update $\vd{\Delta e_i}$ is pedagogical notation used on this page; it is not standard Transformer notation. Standard implementations usually call it the attention output and add it through a residual connection. The addition itself is standard: it is the residual connection around the attention sublayer.

Keep in mind: $\vp{e_7'} = \ve{e_7} + \vd{\Delta e_7}$. The right branch computed the update, the left branch carried $\ve{e_7}$ unchanged, and the plus joins them. That plus is the residual connection.
