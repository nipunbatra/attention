Why we are here: the crudest possible model, predicting from the last token alone, shows what "context" has to buy us.

Baseline: only the last token

This section is the crudest model on purpose. Only the last token reaches the output head, so the prediction is a function of one row of $d_{\text{model}}$ numbers. Switch the context in the widget and watch the bars: nothing moves. The table further down shows why, coordinate by coordinate. The word is the and the position is 10 in both sentences, so the starting representation is the same row of numbers, and the same row of numbers gives the same probabilities. The output head cannot tell a river scene from a bank branch, so it hedges across eight candidates. The sentence to remember: a prediction can only use what reaches it, and here almost nothing does.

Suppose the prediction uses only $\ve{e_t}$, the current token's representation. Right now that is still the starting row $\ve{e_t^{(0)}}$ from section 01.

Feed it straight into the output head; nothing else enters the computation: $$\ell = \ve{e_t}\,W_{\text{vocab}} + b, \qquad p(x_{t+1}\mid x_{\le t}) = \operatorname{softmax}(\ell)$$

Using only $\ve{e_t}$ throws away most of the context. Same last token, same position, same numbers, so the earlier tokens cannot change the answer, however much they matter.

The distribution is almost flat: eight candidates, all near the same height. The model cannot prefer water to teller because, from its point of view, the two sentences are the same sentence. The table shows that sentence, coordinate by coordinate.

The only input, in both contexts

Keep in mind: the output head sees one row of numbers. If the context is to matter, the context has to be written into that row before it arrives.
