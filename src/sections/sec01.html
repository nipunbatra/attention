A language model reads the tokens so far and assigns a probability to every possible next token: $$p(x_{t+1}\mid x_1,\ldots,x_t)$$

To predict the next token well, the model needs a useful representation of everything relevant in the preceding context.

A token embedding and a position vector have the same width:

$$\ve{e_i^{(0)}} = \text{tok}_i + \text{pos}_i$$

The result still has $d_{\text{model}}$ numbers. The superscript $(0)$ means before any contextual update.

Every occurrence starts from its token's lookup row. Context will change the representation of this occurrence, not overwrite the lookup table.

Keep in mind: the model is judged only by the probability it puts on the right next word, and the only thing it can work with is a row of numbers per token.
