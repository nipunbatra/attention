Baseline: a fixed window of w tokens

Give the model more context by concatenating the last $w$ representations into one long row. A larger matrix can read that row. The first diagram uses an MLP with eight hidden units. The “Inside the window” slider connects the selected words to a simpler linear head, matching the equation that follows. In both sketches, each token adds four input nodes. At $w=3$, river is outside. At $w=10$, every token fits because this sentence is short. Changing the window changes the required parameter shapes. These are architecture sketches, not trained predictions for every window size. A network can learn to use the content it receives, but it gets no information from beyond its fixed window.

The last $w$ token rows can feed a fixed network. Its first layer reads all $w$ rows at once, followed by a hidden layer and one output per vocabulary word.
