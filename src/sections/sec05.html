Why we are here: weights should come from what a token needs and what a token has. Search gives us a familiar analogy for those two roles.

A detour through search: Query, Key, Value

Before attention touches a sentence, it helps to see the same three roles somewhere familiar. A video site has to answer two questions for every item: does it match the search, and what should it hand back? Those are different jobs, so each video keeps a key for matching and a value for returning. The first spreadsheet puts the query in the top row and the six keys beneath it, so you can compare them column by column; the score on the right is the dot product. Switch to the overfitting question and watch which row wins. The sentence to remember: keys decide whether to retrieve, values are what gets retrieved.

Leave language for a moment. A website hosts six educational videos and a user types a question. The site has to decide which videos match and what to return. Those are two different jobs, so every item carries two representations.

The search: the question becomes a Query row, and every video has a Key row

Query

Matching is a dot product between the query and each key. At this stage the site looks at nothing else about the item.

$$s_j = \vq{q}\cdot \vk{k_j}$$

$\vq{q}$ = query representation, $\vk{k_j}$ = key of item $j$, $\vv{v_j}$ = value of item $j$.

QWhat am I looking for?the query, formed by the searcher
KWhen should you retrieve me?the key, one per item, used only for matching
VWhat information do I send if retrieved?the value, one per item, the actual payload

The Value of each video: what comes back if it is retrieved

The key is used to decide whether something matches.
The value is the information we actually retrieve.

A high score says retrieve Backpropagation, but what arrives is its value, not its key. For this toy lookup, take the highest-scoring item. Real search engines usually rank several results; attention instead mixes values using soft weights.

Keep in mind: a score comes from the query and the key alone. The value plays no part in matching; it only travels once its item is chosen.
