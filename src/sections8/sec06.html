Generate: the answer supplies the next query

One prediction is not yet an answer. Generation repeats the same forward pass with a longer prefix: choose the most probable token, append it as a new row, and let that row ask the next question. Step through it below. The question mark predicts two; the appended two row forms its own query, reads the scene again, and predicts the end marker, which stops generation. The parameters never change and the sixteen image rows never change; only the last query does. Look at the second overlay: the end marker's decision reads the table and the book, not the mugs.
