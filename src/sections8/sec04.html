Two routes, one mask: who may read whom

Part 2 used a causal mask so that no token could read the future. With image rows in front, the mask has two rules. Image rows read only image rows: they are context, not part of the sentence, and they must never carry a later answer word backwards. Text rows read every image row and the words up to themselves. The picture below shows the 21×21 pattern. There is a second way to connect an image to a decoder, the cross-attention of Part 4, where the text supplies queries and a separate visual memory supplies keys and values; our numbers use the shared prefix, and the same mask.

  • Image rows (1 to 16) read image rows only.
  • Text rows (17 to 21) read every image row and the text so far, including themselves.
  • Masked scores are $-\infty$, so their weights are exactly 0.
