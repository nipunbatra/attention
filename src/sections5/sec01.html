What should this image classifier answer?

Our text model used information from earlier words to predict the next token. Now we want one answer about a whole image. We will follow the image on the left through every calculation, then use the second image to see why learning is necessary. A block here means one filled 2×2 square in this small picture.

The image is the input. “Two blocks” or “one block” is the observed label used for training.

Our image has 4 rows × 4 columns × 1 channel. Dark pixels are 0; the two filled blocks use 1 and 2.

These are brightness values, not token IDs. Changing a pixel changes the numerical input directly.

In the text lesson

She deposited money …

One word/token → one embedding row.

For this image

One small patch of pixels → one embedding row.

The rows will exchange information through attention.

A patch is a piece of the input, not necessarily an object. A photograph’s patch may cut through part of a face or a tree.

image → patch embeddings → attention → image answer

We will use two numbers per embedding so that every multiplication fits on the page.

First we inspect one fixed set of starting weights. Later we train those same weights and run the images through again.

This small model contains patch projection, position addition, one attention update, and a class head. We add the rest of a full ViT after this calculation makes sense.

Notation follows the text lessons: $e$ is a representation, $q$ and $k$ are used for matching, and $v$ is the information sent. We introduce $r_j$ for the raw pixels of patch $j$ because those four numbers are not yet its two-number embedding.
