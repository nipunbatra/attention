What should this image classifier answer?

Our text model used information from earlier words to predict the next token. Now we want one answer about a whole image. Start with this tabletop scene: two mugs, a book, and a plant. How could an attention model turn those pixels into an answer? After seeing what a patch contains, we will switch to a separate 4×4 worksheet so that we can calculate every number.

The input is the picture. Its training label is two mugs.

Each rectangle supplies one input row. The grid is fixed before the model knows where the mugs are.

One patch contains a mug edge, tabletop, and book.

The tabletop scene has more pixels than we can multiply by hand. The following worksheet uses two filled blocks instead of mugs. It is a separate numerical example, not a downsample of the scene and not evidence that a model trained on two block images can count mugs.

Our worksheet counts filled 2×2 blocks. These are new inputs with labels “two blocks” and “one block”.

Our image has 4 rows × 4 columns × 1 channel. Dark pixels are 0; the two filled blocks use 1 and 2.

These are brightness values, not token IDs. Changing a pixel changes the numerical input directly.
