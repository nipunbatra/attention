An architecture specifies a computation. A training objective determines what it is rewarded for.

What has the model learned?

We now have a complete route from an image to a loss. Our arithmetic used hand-chosen parameters so that we could inspect every operation. A useful vision model instead learns its parameters from data. Supervised classification is one way to train that encoder, but not the only one. The next part keeps image representations and changes the training signal.

A patch contributes through its key, which affects the weights, and its value, which supplies information to the mixture.

So far: an image label supplies a classification loss.

  • Two views of an image can supply a matching task.
  • Hidden patches can supply a reconstruction task.
  • A teacher model can supply a feature target.

Vision Part 2 asks what these objectives encourage the image representation to retain.

What the worksheet does and does not establish

The page demonstrates patch extraction, a shared projection, position addition, a class token, self-attention, residual addition, and a derived class probability. It does not measure recognition quality. Attention diagrams show a mixing operation, not a complete causal explanation of a trained prediction. The earlier photo-based article explored a different CNN-feature proxy; this numerical example does not depend on that external model or equate its features with ViT patch attention.
