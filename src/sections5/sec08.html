The small example let us inspect every value and train a complete attention classifier. A practical Vision Transformer uses wider representations and several encoder blocks. We can scale the shapes without losing track of the input: count the patches, work out the raw width of each patch, choose a representation width, and add the class token. The architecture then adds normalization, multiple attention heads, and a feed-forward network.

Here we choose a model width of 384. Every learned position vector and the CLS row also has 384 numbers.

Repeat the blocks. A final normalization and class head read the final CLS row.

Each head reads all 384 input features. Its own projections make 64-number queries, keys, and values.

Concatenate the six messages. $W_O$ returns an update with the same width as $E$.

Two details worth returning to

Patch positions describe slots in the image. Without them, permuting the patch inputs permutes their self-attention outputs. If CLS stays in its slot, its output is unchanged by that patch permutation. This is permutation equivariance of the patch rows and invariance of the CLS readout, not invariance of the whole output matrix.

Smaller patches create more rows. For this 224×224 image, changing the patch side from 16 to 8 raises the patch count from 196 to 784. Including CLS, the attention matrix grows from 197×197 to 785×785. That counts score entries per head, not the complete runtime or all model memory.

The full encoder pattern follows the original Vision Transformer and its reference implementation. Our two-image model demonstrates a calculation and a learning loop; it does not reproduce those trained models. Continue to Vision Part 2: learning visual features.
