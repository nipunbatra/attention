The class token uses a query to choose which values to mix.

Let the class token read the image

We now have the input that self-attention expects: a matrix of equal-width rows. Each row supplies three projections. Its query controls what it reads; its key helps other queries determine a mixing weight; its value supplies the information those queries receive. We will work the CLS query first because our classifier uses the updated CLS row. The same calculation also updates all four patch rows.

$\vq{Q}=EW_Q,\quad\vk{K}=EW_K,\quad\vv{V}=EW_V$

# E: [5, 2]; each W: [2, 2]
Q, K, V = E @ W_Q, E @ W_K, E @ W_V

$W_Q=W_K=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix}$

CLS query:

$\vq{q_0}=(1,1)W_Q$

$\phantom{q_0}=(0.5,0.5)$

Here $q_j=k_j$ only because we set $W_Q=W_K$. The two roles are different.

$s_{0j}=\vq{q_0}\vk{k_j}^{\top}/\sqrt{d_k}\qquad d_k=2$

For patch 4: $(0.5\times2.5+0.5\times2.5)/\sqrt2\approx1.768$.

A dot product adds $d_k$ coordinate products. With independent, zero-mean, unit-variance query and key coordinates:

$\operatorname{Var}(qk^\top)=d_k\qquad\operatorname{Var}\!\left(\frac{qk^\top}{\sqrt{d_k}}\right)=1$

The division keeps scores from tending to grow just because we use wider matching vectors. Otherwise softmax can become very sharply concentrated.

This is a scale adjustment. It does not make the query and key unit-length vectors.

$\alpha_{0j}=\exp(s_{0j})/\sum_{t=0}^{4}\exp(s_{0t})\qquad\sum_j\alpha_{0j}=1$

scores = Q @ K.T / math.sqrt(2)  # [5, 5]
A = scores.softmax(dim=-1)       # normalize each receiving row

The square-root factor prevents dot products from tending to grow with matching width under a common initialization model. Excessively large score differences would make softmax concentrate sharply and leave small gradients for many alternatives. It is a scale adjustment, not cosine normalization. Our row width is two, so the divisor is $\sqrt2$. The displayed exponential column uses the mathematical formula; the code may subtract the largest score before exponentiating for numerical stability, which gives the same weights.
