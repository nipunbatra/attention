What is in a patch and where it sits are different pieces of information.

Keep positions and add a class token

Patch 2 and patch 3 both contain only zeros. Their content embeddings are identical even though one is at the top right and the other is at the bottom left. Add a position vector to each patch embedding before attention. The position vectors have the same width as the embeddings. They do not append a special position coordinate.

$\ve{e_j}=\ve{e_j^{\mathrm{patch}}}+p_j\qquad (1\times2)+(1\times2)=1\times2$

The two zero patches now have different input rows because they occupy different slots.

Prepend a class token with initial content $c=(1,1)$. It has no pixel patch.

After attention, use the updated CLS row for image classification. Its initial row is shared across images; the information it receives depends on the image.

# cls: [1, 1, 2]; patch_rows: [1, 4, 2]
E = torch.cat([cls, patch_rows], dim=1) + position
# E: [1, 5, 2]; position: [1, 5, 2]

Row $0$ is CLS. Rows $1,2,3,4$ follow the patches in raster order.

Swap patch 1 and patch 4 before attention. Keep CLS in row 0.

Without positions, patch outputs follow the permutation: self-attention is equivariant. The fixed CLS output is unchanged.

With positions attached to slots, the swapped content produces a different CLS output in this example.

There is no causal mask in this image encoder: every patch is already known. This differs from predicting the next word of an unfinished sentence. Positional information lets the encoder distinguish arrangements, but it does not force attention to stay local or guarantee that a particular arrangement will be classified correctly.
