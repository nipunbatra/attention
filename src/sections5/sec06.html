The contextual CLS row is a representation. A class head converts it into logits.

Use the updated class row

We have finished the attention calculation, but we do not yet have a prediction. A classifier maps the updated CLS row to one logit per candidate class. A second softmax normalizes those class logits. This softmax answers a different question from attention: which output class gets probability, rather than how to mix the input values.

$W_{\mathrm{class}}=\begin{pmatrix}0.5&0\\0&0.25\end{pmatrix},\qquad b_{\mathrm{class}}=(0,0)$

$z=e_0'W_{\mathrm{class}}+b_{\mathrm{class}}$

logits = E_next[0] @ W_class + b_class  # [2]
probabilities = logits.softmax(dim=-1)

For this worksheet, suppose the observed label is class A.

target = torch.tensor([0])  # class A
loss = F.cross_entropy(logits[None, :], target)
