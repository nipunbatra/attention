Values and the update

Phase B of Part 2, on the image. Each row's value $\vv{v_j} = \ve{e_j} W_V$ is what it sends if it is read; before training the value axes copy brightness and contrast. Multiply each value by its weight, add the seventeen results, and CLS holds a message $m_0$. The output projection $W_O$ turns the message into an update $\vd{\Delta e_0}$ on the four named axes, and the residual addition gives $\vp{e_0'} = \ve{e_0} + \vd{\Delta e_0}$. The mix table has thumbnails on its rows; the scatter plot shows the CLS point moving toward the patches it read. One intervention on the way: change only $W_V$ and watch every weight stay put.

Each row's value is what it sends: $\vv{v_j} = \ve{e_j} W_V$. The message CLS collects is $m_0 = \sum_j \va{\alpha_{0j}}\,\vv{v_j}$, and $W_O$ maps it back to the axes of $\ve{e}$.

$m_0 \to \vd{\Delta e_0} = m_0 W_O \to \vp{e_0'} = \ve{e_0} + \vd{\Delta e_0}$

$W_O$ decides where each message coordinate lands: two numbers in, four out, on the axes of $\ve{e}$.
