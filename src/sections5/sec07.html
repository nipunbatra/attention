The original Vision Transformer uses a pre-norm encoder: normalization precedes each attention and feed-forward sublayer, with a residual addition after each one. A final normalization follows the stack. The diagram below describes that architecture. It is not the numerical model we just evaluated; inserting LayerNorm into that two-coordinate worksheet would change its numbers.

E = E + mlp(norm2(E))

Halving the patch side gives four times as many patch tokens and about sixteen times as many attention entries.

A patch projection can be implemented as a convolution whose kernel and stride both equal the patch size. It applies the same learned linear map at each nonoverlapping patch location. This equivalence does not make a ViT encoder identical to a conventional convolutional network. Global attention can mix distant patches in one layer; local convolutions build spatial context according to their kernels and depth.

The architecture above follows the original ViT description and reference implementation. Their trained systems use more dimensions, layers, and data than this worksheet.
