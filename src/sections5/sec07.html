Learn from the two images

Train on both images: one has two occupied blocks, and one has only the lower-right block. Each image goes through the same model and gets its own cross-entropy loss. We average the two losses before taking an optimizer step. That step changes the patch projection, CLS and position parameters, attention projections, and classification head together. The page runs these calculations locally; the displayed training results come from the model we have just worked through.

# Two images produce two rows of class logits.
logits = model(images)                 # [2, 2]
loss = F.cross_entropy(logits, labels) # mean over both images

$R$ stacks the flattened patch rows $r_1,\ldots,r_4$. Dashed boxes contain learned parameters; solid boxes show computations.

Both the weights $A$ and the values $V$ receive gradients.

On the next forward pass, new parameters produce new embeddings, queries, keys, values, and predictions.

optimizer.zero_grad()
loss.backward()  # compute a gradient for each learned parameter
optimizer.step() # update the parameters using those gradients

$\theta_{\mathrm{new}}=\theta-\eta\,\nabla_\theta L$

The mean loss falls, although the two-block image gets worse on this first step.

The optimizer is fitting both examples together. One step need not improve every example.

optimizer.zero_grad()
F.cross_entropy(model(images), labels).backward()
optimizer.step()

The same model now gives the correct label most of the probability for both training images.

We have shown learning on two examples. Try new one- and two-block images, with different positions and brightnesses.

The numerical model contains one attention head, two-number representations, one residual addition, and the class head. It has no LayerNorm or feed-forward sublayer. The next section adds those components to the architecture rather than silently inserting them into the arithmetic we just trained.
