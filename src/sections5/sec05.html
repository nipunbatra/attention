A weight says how much. A value supplies what arrives.

Bring patch information into CLS

The query and keys have produced one mixing amount per source. A scalar amount alone cannot update a two-number row. Each source therefore makes a value vector, $v_j=e_jW_V$. Multiply each source’s value by its own weight, then add the contributions coordinate by coordinate. This returns a message to the receiving CLS row.

Starting with $W_V=I_2$ gives $v_4=e_4=(5,5)$. This equality comes from the identity map—not from the definition of a value.

One weight scales every coordinate in the value from the same source.

Displayed numbers are rounded; calculations keep the unrounded weights.

Each contribution is a vector $\alpha_{0j}v_j$. Now add down coordinate 1, and separately down coordinate 2.

The two-number message $m_0$ combines this image’s source values. Its coordinates are features, not class probabilities.

$W_O=I_2$ leaves the message unchanged here. The new CLS row includes its original $(1,1)$ plus information from this image.

The stored $c$ is still $(1,1)$. It is copied as the starting row for the next image too.

Only a training step changes stored parameters. A forward pass computes new intermediate rows from them.

Stack all five reads. Row $i$ of the message matrix $H$ is the message $m_i$.

$\underbrace{A}_{5\times5}\;\underbrace{V}_{5\times2}=\underbrace{H}_{5\times2}$

Q, K, V = E @ W_Q, E @ W_K, E @ W_V
A = ((Q @ K.T) / math.sqrt(2)).softmax(dim=-1)
E_next = E + (A @ V) @ W_O       # [5, 2]

All reads use the same original input rows. The classifier will use updated row 0; patch rows remain available for later layers.

Try another receiving row

The receiving query changes; the source keys and values are still those of the original image-token rows. A large attention weight describes the amount of a source value in this weighted sum. By itself it does not establish that a patch caused the final class decision.

What did changing only values do?

Query and key computations were untouched, so each of the five weights stayed unchanged. The second coordinate of every value doubled, which doubled the second coordinate of the message. This comparison returns to the identity value map for the main classifier calculation.
