Keys chose the weights. Values supply the vectors we add.

Mix values and add the update

The attention weights are scalar mixing amounts. To get a vector, multiply each source value by its weight and add the results. This mixture belongs to one receiving query. Here it belongs to CLS. We then project the mixture back to representation width and add it to the original CLS row through the residual connection.

$W_V=I_2$, so $\vv{v_j}=e_j$ in this worksheet.

$m_0=\sum_{j=0}^4\alpha_{0j}v_j$. Keys are used for matching; values are used in this sum.

$W_O=I_2$, so $\vd{\Delta e_0}=m_0W_O=m_0$.

This update changes the representation for this image. It does not overwrite the learned CLS parameter $c$.

$A:\;5\times5\qquad V:\;5\times2\qquad AV:\;5\times2$

message = A @ V                  # [5, 2]
delta = message @ W_O             # [5, 2]
E_next = E + delta                # residual update

Each output row reads the same original input matrix. No row reads a partly updated neighbor.

A global attention layer already connects every patch to every other patch. Deeper layers transform and combine that information again.

The complete updated matrix

All five rows are updated in parallel from the same input matrix. We do not update CLS first and then let the other rows read the already-updated CLS. That would be a different calculation. The classifier will select row 0 from this output, but the encoder can retain all patch rows for tasks that need spatial information.
