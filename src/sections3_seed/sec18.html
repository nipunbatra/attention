Why we are here: one attention sublayer gives one update. Real models stack many, and each one starts from the previous result, not from scratch.

Layer after layer

Everything so far used the token embeddings as the starting point, and after one attention sublayer each token has moved once. Real models repeat that move many times. The part that matters is where the next layer starts: from the representations the previous layer produced, not from the embeddings again. So layer 2 builds its queries, keys and values out of vectors that already contain context.

Apply the layers one at a time below and watch bank's row in the last table move away from its embedding. The sentence to remember: the representation is updated in place, layer after layer, and the raw embedding is only the first row.

$\ve{e_i}$ is the raw token embedding only at layer 0. After every attention layer it is a representation changed by context, and the next layer computes its $\vq{Q}$, $\vk{K}$, $\vv{V}$ from that, not from the original embedding.

$$\ve{e_i^{(0)}} = \text{token embedding}_i + \text{position}_i, \qquad \vp{e_i^{(1)}} = \ve{e_i^{(0)}} + \vd{\Delta e_i^{(0)}}, \qquad \vp{e_i^{(2)}} = \ve{e_i^{(1)}} + \vd{\Delta e_i^{(1)}}, \;\ldots$$
