The current deck has excellent material but is still too mechanism-first.
Refactor the MAIN LECTURE so that it has the same pedagogical quality as
the "Beyond Attention" lecture.

========================================================
CORE STORY
========================================================

The lecture should revolve around five questions:

1. An encoder expects a sequence of vectors.
   HOW CAN AN IMAGE BECOME A TOKEN SEQUENCE?
   → split into patches
   → flatten each patch
   → shared linear projection

2. The same projection is used at every patch.
   HOW DOES THE MODEL KNOW WHERE A PATCH CAME FROM?
   → learned positional embeddings

3. We now have 196 patch representations but want ONE image label.
   WHICH REPRESENTATION SHOULD WE READ?
   → remind students about pooling
   → reuse [CLS] from previous lecture

4. HOW DO THE PATCHES EXCHANGE INFORMATION?
   → reuse Transformer encoder/self-attention
   → Q,K,V all come from the SAME image stream
   → contrast with translation cross-attention

5. HOW DOES ONE IMAGE REPRESENTATION BECOME A CLASS?
   → final CLS
   → linear class head
   → 1000 logits
   → softmax

Then finish:

The classifier stores one learned vector for each fixed class.

WHAT IF THAT CLASS VECTOR CAME FROM LANGUAGE?

→ NEXT LECTURE: CLIP

========================================================
ADD A "LEARNED VS COMPUTED" SLIDE
========================================================

TITLE:
What is stored in the model, and what changes with the image?

LEARNED PARAMETERS:
- patch projection W,b
- position embeddings
- starting CLS vector
- Transformer weights
- classifier weights/biases

COMPUTED FOR EACH IMAGE:
- patch embeddings
- Q,K,V
- attention weights
- contextual patch states
- final CLS
- logits / probabilities

Important takeaway:

W_Q,W_K,W_V are learned.
Attention weights are computed separately for each input.
