Freeze both encoders. Write the candidate captions. The list is the classifier.

Classify by writing candidates

After training, the encoders stay fixed. To classify a scene, write one caption per class, encode each into a unit vector, and let the image vector score them by cosine. Those caption vectors play the role of the class head's rows, and you can rewrite them at any time. The widget below runs every combination the toy allows: any scene from the batch, several candidate lists, a prompt template, and a temperature. Try the list that leaves out the right answer, then the one-mug scene the model never trained on. Every result comes from the same frozen parameters; nothing is retrained between clicks.

For fixed vectors, a positive temperature never changes which candidate wins. It changes how sure the softmax looks.

Zero-shot classification is retrieval against a list you wrote: encode the candidates, score by cosine, softmax over the list. The encoders do not move; the list does. A high probability compares candidates; it does not certify a description.
