A match score is not a truth judgment

There are two different claims to separate. Contrastive training can learn representations that transfer to new tasks. A particular softmax score, however, only compares the candidates supplied to it. Removing the correct candidate does not create an automatic "none of the above" output. Evaluation must account for that limitation.

$p(T_j\mid I,\mathcal C)=\dfrac{\exp(C_j/\tau)}{\sum_{k\in\mathcal C}\exp(C_k/\tau)}$

  • The candidate set $\mathcal C$ is chosen by us.
  • Adding or removing a candidate changes the denominator.
  • A smaller temperature can make the winner look more certain without adding image evidence.

A high candidate probability is not calibrated confidence that a description is true in the world.

Two images may share a valid description. A one-positive-per-row batch objective still treats the other pairing as a negative.

Batch construction, duplicate handling, and richer positive sets matter. Larger batches can add both useful competitors and false negatives.

Zero-shot means no task-specific training in that evaluation. The encoders have already learned from image-text data.

Try a real model separately

The original browser CLIP demo accepts photos and candidate prompts and downloads a pretrained model. It requires network access and browser support; nothing in this lesson depends on it. Its pretrained embeddings must not be confused with the three-coordinate toy used here. The official CLIP examples show normalization, zero-shot classification, and caching text features.

Checks before using this in an application

Evaluate the specific images, language, candidate classes, and errors that matter for the task. Pretraining on web captions does not remove biases or guarantee robust counting, spatial reasoning, or domain transfer. The CLIP model card records intended uses and limitations.

Why a collapsed representation is not useful

If every image and every caption returns the same unit vector, all scores tie. Each candidate then receives $1/N$, so each directional loss is $\log N$. With three pairs, that is . The objective rewards identifying the observed partner among competitors, not simply increasing every match score together.
