Every extra pair is a competitor for every other pair. A collapsed model scores log N, whatever N is.

Grow the batch

With three pairs, a caption has two wrong images to reject. Real CLIP uses batches of tens of thousands of pairs, so each caption must beat tens of thousands of images at once. To see the effect on our toy, add five more scene and caption pairs that the model never trained on and watch the denominators grow. The slider keeps the trained parameters fixed; only the batch changes. Two things happen: the observed pair's probability drops as the list lengthens, and captions that are true of several scenes start to compete. The second thing is the batch's dirty secret: a wrong pair by construction can be a right pair in fact.

The loss rewards telling the observed pair from its competitors. More competitors make that harder, and more informative.

If every image and every caption had the same vector, every score would tie. Contrastive training punishes that with $\log N$ per direction.

Scene A against the eight captions of the batch, trained parameters

A batch objective treats every off-diagonal pair as wrong. Web batches hold many such false negatives.

Batch size sets how many competitors each pair must beat. The collapsed model scores exactly $\log N$; a trained model is measured by how far below that line it gets.
